## 清洗和标签

按来源方要求移除正例 VNRRPCFSALT，未改标阴性；不能将删除作为 Pro 排除规则有效的证据。保留删除前备份用于逐字段核验。原正负文件 ca_label=1 均表示已验证位点掩码，正负结局按文件来源决定，分别建立 tested_mask、label_mask、confirmed_negative_mask。未标注的 Cys 不作为阴性。坐标和生化特征未改写。

训练 16 条记录、19 标注位点（5 正、14 负）；两个未标注 Cys 不进入损失。实验监督权重均为 1；验证、模拟、低精度数据不训练。特征固定按 [1,300,1,38] 归一化，不拟合验证统计量。

## 划分与泄漏防控

最终模型固定 50 轮使用全部监督样本，母蛋白留出仅作诊断。3 个推断组中，一组含全部阴性，留出后训练只剩正类，故跳过；其余两个可评估留出正位点均未命中。无独立阴性测试，不能估计可靠总体 accuracy、precision 或 F1。

母蛋白组依历史完整序列的唯一精确包含关系推断，不是实验元数据或同源聚类。训练与 2MI1 无互为完整子串匹配，不等于全面排除同源泄漏。反馈会拒绝重复 observation_id、重复序列/位点和留出母蛋白冲突；全面同源去重仍待补充。
