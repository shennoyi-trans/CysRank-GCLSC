## 已确认的任务与数据问题

1. **二分类监督没有训练效率排序。** AGCKNFFW 的 Cys3 与 KTFTSC 的 Cys6（映射 SST Cys14）都标为正例，训练回代分数已分别为 0.973279 和 0.980683。损失要求两者为阳性，没有要求前者更高；不能把 SST 较低效率的 Cys14 擅自改为阴性。
2. **训练规模小且来源混杂。** 只有 22 个位点拟合 364 个可训练参数。14 个负位点全部归于同一母体；8 个正位点来自 5 个母体组。全部正例无二硫键，13/14 负例带二硫键。完整蛋白实验截出的负例与短肽正例的反应对象/状态并不等价。这个问题是来源和任务不一致，不能直接宣布历史负例标错。
3. **高训练命中不代表学会反应机制。** 仅结构特征也能达到 22/22 训练命中，仅序列上下文可达 21/22。来源、片段长度与截断环境均可能成为区分类别的线索；本审计不能证明某一个线索是唯一原因。
4. **测试相关片段已进入训练。** 两个 SST 片段属于同一来源组，已包含在正式训练中；不具备独立验证资格。诊断移除整个 SST 来源组后两者分数明显下降，说明高分存在训练重叠依赖。
5. **需核对同母体位点的实验对象。** 母体位点 245 在 VHKECCHGDLL 中标正，在 VHKECCHGDLLECADDRADLAK 中标负，并伴随二硫键/邻近原子数差异；这可能是不同反应对象或条件，而非标签录入错误，需原始实验记录区分。母体位点 199 在 LRCASIQKFGER 与 CASIQKFGER 中重复为负，当前各按一个监督样本计权；须确认是否独立实验，不能自动当作两次独立证据。
6. **训练结构与反应前状态仍未统一。** 此轮主要更新正例 SASA，负例沿用历史特征，完整计算定义尚未独立复算；结构编码仍使用片段环境。当前测试使用封端、还原、短时松弛的完整 14 肽，训练并未建立同一标准下的全部结构。即使 SASA 更新正确，也不能修复整体表征和监督任务差异。

## 当前模型为何偏向 Cys14

分类头为线性层，可精确按输入块拆解 logit。以下是 100 个生产结构中 `Cys14 − Cys3` 的平均贡献，不是概率差或因果效应：

| 特征块 | 平均 logit 差 |
| --- | ---: |
| 冻结 ProteinMPNN 结构表征 | +1.395177 |
| 局部序列上下文 | +0.720885 |
| SASA | +0.003356 |
| 邻近原子数 | +0.006093 |
| 二硫键、前位 Pro | 0 |
| 总计 | +2.125512 |

偏向 Cys14 的直接数值来源主要是结构和序列表征；不能据此将失败主要归因于 SASA、二硫键或缺少 pKa。编码器未直接使用氨基酸输入，序列信息来自单独的 ±5 位 one-hot 上下文。片段外以 X 填充，因此边界也进入序列表征。

## 固定设置的诊断重拟合

各项沿用同一种子、50 epochs 和优化器，不保存或替换正式模型；结果仅用于定位依赖，不能用来择优宣称验证成功。

| 诊断 | 训练命中率 | Cys3 更高的生产帧 | Cys3 均分 | Cys14 均分 |
| --- | ---: | ---: | ---: | ---: |
| 原设置复放 | 22/22 | 7/100 | 0.891827 | 0.985284 |
| 去掉全部生化特征 | 22/22 | 7/100 | 0.878919 | 0.982984 |
| 仅结构表征 | 22/22 | 7/100 | 0.688467 | 0.956867 |
| 仅序列上下文 | 21/22 | 0/100 | 0.873024 | 0.950119 |
| 仅四项生化特征 | 14/22 | 36/100 | 0.437503 | 0.444175 |
| 去掉 SST 来源组（20 个训练位点） | 未用于选择 | 26/100 | 0.416794 | 0.523777 |

不同重拟合模型的分数未校准，不能直接将分数升降当作效率变化；100 帧有时间相关性，也不是 100 个独立实验。

## 建议的修复顺序

先明确目标是“可否反应”还是“同一肽中谁更高效”。如要训练后者，需要匹配反应条件的定量效率或成对排序监督，并保留独立来源测试；现有两个阳性标签不能提供该信息。随后核对同母体重复位点、实验对象和化学状态，统一正负样本的完整结构与特征计算流程，再按母体/同源分组补充可用的负例与验证数据。

当前不应为 SST 单个预期排序翻转标签、挑选特征或调整权重。审计支持“任务监督和数据分布不足以支撑效率排名”，尚不支持“找到了一个修好即能恢复实验排序的代码 bug”。
